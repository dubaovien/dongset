⚡ Dữ liệu dông sét - HYMETNET

Lấy dữ liệu từ http://hymetnet.gov.vn/dongset/
Lưu ý quan trọng: Đây là API nội bộ, không có tài liệu công khai nên mình chưa biết chính xác endpoint trả JSON nằm ở đường dẫn nào bên dưisland /dongset/, và định dạng dữ liệu trả về ra sao. File này gọi thẳng vào URL bạn cung cấp — nếu đó là trang HTML (không phải JSON) thì cần bạn mở DevTools (F12 → tab Network) trên trang thật của họ, tìm request nào trả JSON (thường có dạng .../api/... hoặc .../data...json) rồi sửa biến API_URL bên dưới. Ngoài ra do đây là site .gov.vn, khả năng cao sẽ bị chặn CORS khi gọi từ trình duyệt ở domain khác — xem phần xử lý lỗi bên dưới.
